# QA Checklist for Reviewing an AI Response

Work through each section in order. Tick each box only when you have checked it.

## 1. Before you start

- [ ] I have read the full prompt, including any format or length instructions.
- [ ] I have read the whole response, not just the first part.
- [ ] I know what the guidelines say about this type of task.

## 2. Accuracy

- [ ] Facts, names, dates and numbers are correct.
- [ ] Nothing is invented or unsupported by the prompt or source text.
- [ ] Claims that could be wrong have been verified from a reliable source.
- [ ] Calculations, if any, are correct.

## 3. Relevance and instructions

- [ ] The response answers the question that was asked.
- [ ] It follows every instruction, such as length, format, tone and number of items.
- [ ] It does not add unneeded or off-topic content.

## 4. Completeness

- [ ] All parts of the prompt have been answered.
- [ ] Important points or steps are not missing.
- [ ] There is enough detail for the reader to use the answer.

## 5. Clarity

- [ ] The response is easy to read and well organised.
- [ ] The language is plain and suits the reader.
- [ ] There are no confusing sentences, repeated points or spelling and grammar errors that make it hard to follow.

## 6. Safety and tone

- [ ] The response is polite and appropriate.
- [ ] It does not contain harmful, misleading or inappropriate content.

## 7. Comparing two responses

- [ ] I have scored both responses with the same standard.
- [ ] I have not preferred a response only because it is longer or more confident.
- [ ] I can explain the difference between them in one or two sentences.

## 8. Writing the final assessment

- [ ] I have named the better response, or said they are about equal.
- [ ] I have given the main reasons, pointing to the exact parts of the response.
- [ ] I have flagged serious issues, such as factual errors or ignored instructions.
- [ ] My assessment is consistent with the guidelines and with my earlier reviews.

## 9. When to escalate

Flag the task for review instead of guessing if:

- [ ] The prompt is unclear or can be read in more than one way.
- [ ] The guidelines do not cover the situation.
- [ ] You cannot verify an important fact.
- [ ] The response contains sensitive or harmful content.
