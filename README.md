# QA Checklist for AI Responses

A step-by-step checklist for reviewing a chatbot response before submitting an evaluation.

## What this project is

Careful reviews depend on doing the same checks in the same order every time. This checklist helps catch errors, missed instructions and unclear writing, and makes sure the final assessment is consistent and well documented.

## What is in this repository

- `qa-checklist.md` is the checklist to work through for each response.

## How to use it

1. Read the prompt and the response in full.
2. Work through each section of the checklist in order.
3. Note every problem you find, with the exact part of the response that caused it.
4. Write your assessment only after finishing the checklist.

## Important note

This checklist is a general template written by me. It does not contain material from any client, platform or real project.
